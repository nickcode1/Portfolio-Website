Motive

Have you ever played flappy bird? If you have, you have probably also gotten terribly frustrated with hitting the pipes over and over. So I have outsourced my frustration to the computer terminal.

All jokes aside, I saw an interesting video on YOUTUBE where a guy created a reinforcement algoritm to learn to play flappy bird. This inspired me to try something similar. So I wanted to see if I could apply Model Predictive Control (MPC) to dictate the control of the bird.

MPC is a control method that uses optimization mathematics to determine the best possible control sequence. It is a very inportant control method that can be applied to many domains, including autonomous driving.

The Foundation

Before I could design the controller, I had to first have the physics of the game in hand. I used Clade Code to generate the fountational code of flappy bird using the Pygame libraries.
The game ran exactly like the original flappy bird, producing pipes at random with only 1 input for the user.
After researching MPC, I then constructed a flow chart for the development of the control algorithm.
