Project overview

Building a complete flying system.

This project brings together the mechanical and electrical systems that make a multirotor aircraft work as a whole. The focus is on creating a platform where every subsystem—from structure to control—can be understood, tested, and iterated on.

Core systems

01 / Airframe

Structure

Frame layout, mass distribution, and component placement for a compact, serviceable multirotor platform.

02 / Propulsion

Thrust

Motors, propellers, and electronic speed controls working together to provide balanced and responsive lift.

03 / Flight Control

Stability

Sensors and control electronics translating pilot input into stable, repeatable aircraft motion.
